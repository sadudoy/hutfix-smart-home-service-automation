# Fixora UI Prototype

A responsive, front-end-only home appliance repair marketplace prototype built with HTML, CSS and vanilla JavaScript.

## Run
1. Extract the ZIP.
2. Open `index.html` in a modern browser. No build tools or backend are required.
3. For best results, use a simple local server (e.g. VS Code Live Server), but it is not required.

## Included
- Client workspace: browse/search/filter services, book appointments, view bookings and track a service.
- Repairman workspace: overview, create/edit/publish gigs, booking requests, earnings and professional profile.
- Admin workspace: overview, user management and verification, gig moderation, bookings and analytics.
- Responsive sidebar/navigation, mobile layout, forms, modals, status badges, sample data and toast feedback.

## Notes
- All data is in-memory demo state. Refreshing the page resets changes.
- Booking, payout, contact and moderation actions are simulated.
- There is no authentication, backend, payment gateway, GPS tracking, or real notifications.
